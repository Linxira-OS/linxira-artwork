Scale L / Character Rendering

Actual Chafa output from the Scale L SVG. The source is first rendered to PNG, then encoded as true-color Unicode terminal cells.

01 Block + Geometric

stable silhouette / recommended

OS       Linxira OS
Kernel   7.1.3-arch1-3
Desktop  Plasma 6

        
Best default: uses widely supported block geometry, preserves the L shape and still carries the internal scale.

      

      

        
02 Quad + Sextant
more detail / font-dependent

        
OS       Linxira OS
Kernel   7.1.3-arch1-3
Desktop  Plasma 6

        
Higher local detail: needs a font with newer Unicode quadrant and sextant glyphs, so it is not the robust default.

      

      

        
03 Braille + Technical
highest density / specialist mode

        
OS       Linxira OS
Kernel   7.1.3-arch1-3
Desktop  Plasma 6

        
Most information-dense: visually interesting, but technical glyph substitution makes it unsuitable as a universal default.

      

    

    
Production path: SVG master -> PNG render -> Chafa ANSI output. The rendered ANSI file is packaged, so Fastfetch does not need a runtime converter.
